# Speckle — open data infrastructure for the built environment

The AEC industry runs on files locked inside desktop tools. Speckle turns them into living, structured data: versioned, queryable, viewable, and connected to everything else you use.

**Bring your data in, any way you like:**
- 📂 **Just drop a file** — Revit, IFC, Navisworks and more are processed in the cloud. No plugins, no authoring licenses, no exports.
- 🔌 **Or connect your tools** — connectors for Revit, Rhino, Grasshopper, Blender, SketchUp, Archicad, AutoCAD, Civil 3D, QGIS and more.

**Then actually use it:**
- 🧬 Structured objects with full properties — not opaque geometry blobs
- 🕸️ Version control for design data: diff, branch, and track every change
- 👀 A fast open-source 3D viewer that handles very large federated models
- 📊 Feed live model data straight into Power BI, dashboards, and scripts
- 🤖 Automate checks and workflows that run on every new version
- 🛠️ GraphQL API, webhooks, Python / C# / JS SDKs — built API-first, for developers

Everything core is open source. Start at [speckle.systems](https://speckle.systems), say hi on the [community forum](https://speckle.community), or dive into the code below.
